## Preview locally

1. Clone or download this repository.
2. Keep the `assets` and `samples` folders in the repository structure.
3. Open the root `index.html` file in a browser.
4. Open a sample folder's `index.html` to preview that sample locally.

## Publish updates

1. Save your changes and commit them to the repository.
2. Push the changes to the `main` branch.
3. In GitHub, open **Settings → Pages** and confirm the published branch and folder.
4. Wait for GitHub Pages to deploy, then test the live links.

The folder names in `index.html` and the links above must match the actual folders inside `samples/` exactly.
