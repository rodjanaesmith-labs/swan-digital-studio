## View the website locally

1. Download or clone this repository.
2. Keep the `assets` and `samples` folders in the repository structure.
3. Open `index.html` in a browser to preview the main Swan Digital Studio website.
4. To preview a sample locally, open that sample folder's `index.html` file.

## Publishing updates

1. Save your changes in the repository.
2. Commit and push the changes to the `main` branch.
3. In GitHub, open the repository's **Settings → Pages** and confirm GitHub Pages is configured to publish from the correct branch and folder.
4. Allow a few minutes for the published site to update, then test the sample website links.

## Important folder-name check

The portfolio links in this README and the `SAMPLES` list in `index.html` must use the exact names of the folders inside `samples/`. The current JavaScript uses `beads-shop` for **Bead & Bloom**. If the actual folder is named `bead-and-bloom`, update the `folder` value in `index.html` and the matching README URL so both use the actual folder name.
